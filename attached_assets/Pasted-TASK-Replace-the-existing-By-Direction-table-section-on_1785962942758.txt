The ring must be a functional radial progress indicator, not a plain outline. Concretely: an SVG circle (or two stacked circles) using `stroke-dasharray`/`stroke-dashoffset` (or recharts' RadialBarChart if that's already a dependency — check package.json first) where the colored arc length is proportional to win rate. Starting at 12 o'clock, going clockwise: the win% portion of the circumference is drawn in a bright accent color (green, matching this app's existing win-color convention used elsewhere e.g. RRR histogram/win rate displays), and the remaining portion of the circumference is a dim/muted grey stroke (not black, not fully transparent — should read as "track" of the ring, similar to how loading spinners show an unfilled track). A ring at 0% should show almost no colored arc; a ring at 100% should be a full colored circle. Do NOT just draw a static two-tone ring shape that doesn't respond to the actual percentage — verify the arc length changes correctly for different win rates by checking at least two different setup types with different win% in your screenshot.
